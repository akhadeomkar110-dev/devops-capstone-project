# devops-capstone-project

## Project Description

The Customer Accounts microservice is a REST API-based application designed to manage customer account information for an e-commerce website.

The project aims to support creating, reading, updating, deleting, and listing customer accounts containing basic customer information such as names and addresses.

This capstone project focuses on Agile planning, backlog refinement, sprint planning, and the development and deployment of a microservice using modern DevOps practices.
